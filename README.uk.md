# Адресна книга - основи ООП

Базова ітерація вправи з адресною книгою: ООП-дизайн з класами `Field`, `Name`, `Phone`, `Record` та `AddressBook(UserDict)`. Контакти зберігаються в пам'яті; у наступних тижнях додаються дні народження, постійне зберігання та Telegram-бот.

## Стек

- Python 3.12 (тільки стандартна бібліотека)

## Класи

- **`Field`** - базовий клас для будь-якого значення, що зберігається у записі
- **`Name(Field)`** - обов'язковий, непорожній рядок
- **`Phone(Field)`** - рівно 10 цифр, перевірка при створенні
- **`Record`** - володіє одним `Name` та списком `Phone`; підтримує `add_phone`, `remove_phone`, `edit_phone`, `find_phone`
- **`AddressBook(UserDict)`** - ключ за `Name.value`; підтримує `add_record`, `find`, `delete`

## Запуск

```bash
python hw6.py
```

У нижній частині файлу є невелике демо, що створює кілька записів і демонструє API.
